## Juhend projekti täiendamiseks 

 - Tee _Pull request_ et saada projekti uusim versioon.
 - Muudatuste tegemiseks tee uus branch.
 - Salvesta pidevalt, et vajaduse korral katkist koodi tagasi töötava peale kerida.
 - Kui uus täiendus on valmis, _merge branch into main_.
 - Lisa kõikidele *commit*-idele arusaadav lühike selgitus ja kokkuvõte.
